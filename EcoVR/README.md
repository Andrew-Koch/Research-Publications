# EcoVR Project

Conference: SIGGRAPH 2017 VR Village

Technologies: Unreal Engine 4, VR Analytics, C++
Overview

EcoVR is a VR analytics application designed for environmental scientists to analyse longitudinal environmental data. The VR interface allows users to explore environmental changes over time within an immersive 3D world.
