# Research-Publications
This page provides an overview of my research projects and publications. Each entry below links to a dedicated page with more details, screenshots, and source materials.

**Deep Learning Classification**

[2020 Emotion Recognition Classification Methods, ABCs 2020 – 3rd ANU Bio-inspired Computing Conference](https://github.com/Andrew-Koch/Research-Publications/blob/main/Deep%20Learning%20Classification/ABCs2020_Emotion%20recognition%20classification%20methods.pdf)  
Python, PyTorch, Scikit-Learn, Jupyter Notebooks


Compared classical vs deep learning methods for classifying facial emotions using a 5-dimensional PCA reduction of local phase quantization and Pyramid of Histogram of Oriented Gradients. Click the project link for details, and the PDF of the paper.
